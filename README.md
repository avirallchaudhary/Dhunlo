## Download & Installation

The official signed Android release package is available directly in this repository:

* **File:** [`DHUNLO-v1.0.0-release.apk`](DHUNLO-v1.0.0-release.apk)
* **Size:** ~15.17 MB (15,905,542 bytes)
* **Signing Certificate SHA-256:** `33b85da983e857e90511fffaeef596993d8ffaff1e62941cfb48412e7fd2bbaa`

### Installation Steps

1. Download **`DHUNLO-v1.0.0-release.apk`** to your Android device.
2. If prompted, allow your browser or file manager permission to install unknown apps (*Settings > Apps > Special app access > Install unknown apps*).
3. Open the downloaded `.apk` file and tap **Install** (or **Update**).
4. Launch **DHUNLO** from your home screen or app drawer.

*Note: In-place upgrades from previous DHUNLO releases preserve existing database records, downloaded music, playlists, and user settings.*
